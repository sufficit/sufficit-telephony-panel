# Dedicated mosaic-only operator board

## Request and starting state
The dedicated /board page still rendered the normal page's header, explanations,
tabs, retention controls and filter bars before its resource mosaic. The user
requested only the mosaic, with a small filter button and persistent settings.
The preceding 0.10.0 fullscreen target did not satisfy this normal-page layout.

## Delivery
- Version 0.10.1. Authenticated /board renders a separate branch: extensions and
  endpoints, trunks, queues and explicitly selected resource details. No global
  header, navigation, help, legend, retention section or visible filter bar.
- Small SUI filter icon beside the extension count opens a native popover. Text,
  independent text scopes, server, state, observed-channel toggle and optional
  company filtering preserve URL state when the menu closes, on reload and share.
- Language, theme, fullscreen, reconnect, normal-page and settings links live in
  the menu. English remains default, Portuguese and localStorage remain supported.
- Active filters and observation warnings have compact indicators. Error/status
  messages are available inside the menu; observation failures are not treated as
  an empty healthy exchange. Access-denied/login states remain explicit.
- Fullscreen includes the mosaic, menu and selected details. Channel supervision
  still requires the existing explicit confirmation, rendered within that target.
- Normal page retains full controls and information. Even tab=settings on /board
  cannot render the normal settings screen; the menu links to settings at root.
- Software-development, Sufficit Frontend and Impeccable guided the separate render
  branch, SUI reuse, reduced clutter, accessible disclosure and browser verification.
